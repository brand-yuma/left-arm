# コミュニケーションスタイル

## 基本的な傾向

- **例え話を意識的に使う**：概念を説明するとき、具体的な場面・物語に落とし込む癖がある
- **横文字・専門用語を避ける**：AIやテックに詳しく営業経験が少ないため、意図的に平易な言葉で伝えるよう努力
- **我が強い**：かつてはクライアントの依頼の前提を疑い核心に迫るコミュニケーションをしていた。現在はクライアントのフェーズや状況に合わせてアプローチを変えるように
- **背景から話す（結論ファーストが苦手）**：結論より先に文脈・背景を語り始める。自然とストーリーテリング構造になる

## テキストの特徴

- しゃべり言葉に近い。一文が長くなりがち
- 絵文字を割と使う（対面では表情が読まれにくいため、テキストで感情を補っている）
- 対面とテキストのギャップ：対面だと無表情・一定トーンに見られがち。テキストの方が感情豊か

## カジュアルメッセージの文体

- 感嘆符（！）を多用
- 🤔をよく使う（確認・検討・迷い）
- 「〜くらいですかね」「〜気がします」：断言を避ける柔らかい表現
- 「いや、〜」：軽い訂正・補足
- オーナーへは敬語を維持しつつ感嘆符・絵文字でフレンドリーさを出す

### 実例（ギルドメンバーへ）
```
池田大貴
いや、広告で回してるバナーは広告運用の子が作ってくれてます！

リミブレのやつ何枚かと、今回のやつくらいですかね🤔
あと前の足楽の訴求で、バナー生成ワークフローのお試しで作ったやつは残ってた気がします
```

### 実例（クライアントオーナーへ）
```
@王  遠朋🐶🇨🇳 さん
お世話になっております！
マーラータンとはの看板に差し込む用紙ですが、屋外用A1サイズで3766円かかりますがよろしいですか？🤔
よろしければこちらで入稿しておきます！
```

## ビジネスメールの文体

- 冒頭：「相手名＋様 → お世話になっております → 自己紹介」
- 用件は一段落にまとめる。前置きなし、結論から
- 依頼の表現：柔らかい場合は「〜頂けますと幸いです」、直接的な場合は「〜していただけないでしょうか」
- 締め：「よろしくお願いいたします」のみ。「何卒」等の過剰な敬語は使わない
- 署名：苗字のみ（宮崎）
- 絵文字なし。全体的に短く要点のみ。引き算の文体

### 実例
```
蝦名様

お世話になっております。
マーラータン専門店鑫王子のマネージャーの宮崎です。
ご返信が遅くなりました。

オーナーに連絡が入っておりました注文用タブレットの件ですが、こちらで解決しましたので、改めて最短の日程で営業開始の設定を頂けますと幸いです。
よろしくお願いいたします。

宮崎
```

## 口癖・言い回しの癖

### 本人が自覚している癖
- **「そもそも」**：前提に立ち返るのが癖
- **「たぶん」**：ちゃんと調べられていないときに使う
- **「あー、」**：しゃべり言葉がそのまま出る

### 会話から観察できた癖
- **「それこそ」**：例を出すときや話を繋げるとき
- **「みたいな」**：言い切らず近似・感覚値で表現する
- **「〜んだけど」「〜んだよね」**：カジュアルな場面の語尾
- **「で、」**：話を続けるつなぎ
- **「だから」**：理由→結論を繋ぐ
- **「笑」**：絵文字ではなく「笑」。照れや自嘲
- **「正直」**：強調したいとき
- **「〜かもしれない」「〜気がします」**：断言を避け余白を持たせる
- **「あたりが」**：列挙した後のまとめ
