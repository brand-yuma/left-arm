# Layout Rules — 1080×1920 (Instagram Stories /縦型)

## レイアウトの型
**F型（縦一直線・全画面）**

スマートフォンの縦全画面。視線は上から下へ一直線に流れるF型。
背景全面を画像で覆い、グラデーションオーバーレイで可読性を確保する。
テキスト・CTAはすべて中央揃え（`items-center`, `text-center`）で統一する。

---

## ルートコンテナ

```jsx
{/* ⚠️ このサイズのみ relative を使用。absolute は背景と各ゾーンに限定 */}
<div className="w-[1080px] h-[1920px] flex flex-col overflow-hidden relative"
     style={{fontFamily: 'var(--font-body)'}}>
```

---

## 背景画像（全面）

```jsx
{/* BackgroundImage — absolute inset-0 */}
<img
  src="data:image/jpeg;base64,..."
  alt=""
  className="absolute inset-0 w-full h-full object-cover"
/>

{/* GradientOverlay — 上部は透明→中央→下部は暗く（テキスト可読性確保） */}
<div
  className="absolute inset-0"
  style={{background: 'linear-gradient(to bottom, rgba(0,0,0,0.15) 0%, rgba(0,0,0,0.05) 30%, rgba(0,0,0,0.55) 65%, rgba(0,0,0,0.80) 100%)'}}
/>
```

---

## ヘッダーバー（上部 — 相対配置）

```jsx
{/* HeaderBar — 上端から z-10 で前面に */}
<div className="relative z-10 flex flex-row items-center justify-between px-16 pt-20 pb-0">

  {/* ブランドロゴ or ブランド名 */}
  <span
    className="text-[36px] font-bold tracking-wider text-white"
    style={{fontFamily: 'var(--font-heading)'}}
  >
    {brandName}
  </span>

  {/* シーズナルバッジ（右上） */}
  <span
    className="px-6 py-3 text-[24px] font-bold text-white tracking-widest uppercase"
    style={{background: 'var(--color-accent)', borderRadius: '9999px'}}
  >
    {badgeText}  {/* 例: "春限定" "新登場" */}
  </span>

</div>
```

## メインコンテンツ（中央〜下部）

```jsx
{/* MainContent — absolute で下部に固定 */}
<div className="absolute bottom-0 left-0 right-0 z-10 flex flex-col items-center gap-10 px-16 pb-24">

  {/* AttentionLine — アイキャッチコピー */}
  <p
    className="text-[36px] font-semibold text-center text-white/90 tracking-wide"
    style={{fontFamily: 'var(--font-body)'}}
  >
    {eyebrow}  {/* 例: "今だけの特別体験" */}
  </p>

  {/* HeadlineBlock */}
  <div className="flex flex-col items-center gap-5 text-center">
    <h1
      className="text-[96px] font-bold leading-tight text-white text-center"
      style={{fontFamily: 'var(--font-heading)'}}
    >
      {headline}
    </h1>
    <p
      className="text-[36px] leading-relaxed text-center text-white/85 max-w-[800px]"
    >
      {subCopy}
    </p>
  </div>

  {/* Divider */}
  <div className="w-[120px] h-[4px] rounded-full" style={{background: 'var(--color-accent)'}} />

  {/* BenefitList */}
  <div className="flex flex-col items-start gap-5 w-full max-w-[800px]">
    {benefits.map((benefit) => (
      <div key={benefit} className="flex flex-row items-center gap-5">
        <span className="shrink-0">
          <svg width="32" height="32" viewBox="0 0 24 24" fill="none"
               stroke="var(--color-accent)" strokeWidth="2.5" strokeLinecap="round" strokeLinejoin="round">
            <polyline points="20 6 9 17 4 12"/>
          </svg>
        </span>
        <span className="text-[36px] font-medium text-white leading-snug">
          {benefit}
        </span>
      </div>
    ))}
  </div>

  {/* CTABlock */}
  <div className="w-full flex flex-col items-center gap-6 mt-4">

    {/* 希少性テキスト */}
    <p className="text-[30px] font-semibold text-white/90 text-center">
      {credibilityText}  {/* 例: "先着20名限定・今すぐ予約" */}
    </p>

    {/* CTAボタン — 横幅いっぱい */}
    <button
      className="w-full flex flex-row items-center justify-center gap-5 py-10 text-[44px] font-bold text-white"
      style={{background: 'var(--color-accent)', borderRadius: 'var(--radius-btn)'}}
    >
      {ctaText}
      <svg width="40" height="40" viewBox="0 0 24 24" fill="none"
           stroke="currentColor" strokeWidth="2.5" strokeLinecap="round" strokeLinejoin="round">
        <line x1="5" y1="12" x2="19" y2="12"/>
        <polyline points="12 5 19 12 12 19"/>
      </svg>
    </button>

    {/* 注記 */}
    <p className="text-[26px] text-center text-white/70">
      {footnote}  {/* 例: "定員になり次第終了" */}
    </p>

  </div>

</div>
```

## 配置サマリー

| エリア | 配置 | 役割 | AIBAC |
|--------|------|------|-------|
| BackgroundImage | absolute inset-0 | 感情的インパクト | Attention |
| GradientOverlay | absolute inset-0 | 可読性確保 | — |
| HeaderBar | relative z-10 上部 | ブランド認知 + バッジ | Credibility / Attention |
| AttentionLine | absolute bottom z-10 | アイキャッチ | Attention |
| HeadlineBlock | absolute bottom z-10 | 課題共感 + 訴求 | Interest |
| BenefitList | absolute bottom z-10 | 具体的メリット（3項目） | Benefit |
| CTABlock | absolute bottom z-10 | 希少性 + 行動喚起 | Credibility / Action |

---

## `absolute` 使用の制限（このサイズ限定の例外）

```
許可: BackgroundImage の absolute inset-0
許可: GradientOverlay の absolute inset-0
許可: MainContent の absolute bottom-0
禁止: それ以外の要素への absolute の使用
```

---

## コンテンツ文字数制限

| 要素 | 上限 | 理由 |
|------|------|------|
| headline | 14文字/行（2行まで） | 96px × 幅1080pxの限界 |
| subCopy | 28文字 | 2行に収まる限界 |
| benefit各項目 | 20文字 | 1行に収まる限界 |
| badgeText | 6文字 | バッジ幅に収まる限界 |
| ctaText | 12文字 | ボタン幅に収まる限界 |

---

## nanobanana アスペクト比

このサイズで `gemini_generate_image` を呼ぶ前に必ず以下を実行:
```
set_aspect_ratio: "9:16"
```

---

## 禁止事項

- 外部画像URL の使用禁止（Base64のみ）
- 絵文字の使用禁止（SVGアイコンで代替）
- MainContent 内での `absolute` の使用禁止
- テキストの左揃え禁止（`text-center` / `items-center` に統一）
- BenefitList を4項目以上にすることを禁止
