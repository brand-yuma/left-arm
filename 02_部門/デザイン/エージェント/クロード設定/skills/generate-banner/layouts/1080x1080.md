# Layout Rules — 1080×1080 (Instagram Feed / 正方形)

## レイアウトの型
**Z型（全面背景画像 + 対角線視線誘導）**

正方形の全面を画像で覆い、グラデーションオーバーレイで可読性を確保する。
視線は左上（ロゴ）→右上（バッジ）→対角線→左下（見出し）→右下（CTA）と流れるZ型。
336×280の拡張版として設計し、より豊かなコンテンツを展開できる。

---

## ルートコンテナ

```jsx
{/* ⚠️ このサイズのみ relative を使用。absolute は背景・オーバーレイ・コンテンツに限定 */}
<div className="w-[1080px] h-[1080px] flex flex-col overflow-hidden relative"
     style={{fontFamily: 'var(--font-body)'}}>
```

---

## 背景画像（全面）

```jsx
{/* BackgroundImage — absolute inset-0 */}
<img
  src="data:image/jpeg;base64,..."
  alt=""
  className="absolute inset-0 w-full h-full object-cover"
/>

{/* GradientOverlay — 左上は明るく・右下に向かって暗くなるZ型グラデ */}
<div
  className="absolute inset-0"
  style={{background: 'linear-gradient(135deg, rgba(0,0,0,0.05) 0%, rgba(0,0,0,0.10) 40%, rgba(0,0,0,0.70) 75%, rgba(0,0,0,0.85) 100%)'}}
/>
```

---

## ヘッダーバー（上部）

```jsx
{/* HeaderBar — absolute top で固定 */}
<div className="absolute top-0 left-0 right-0 z-10 flex flex-row items-center justify-between px-16 py-12">

  {/* ブランドロゴ or ブランド名（左上） */}
  <span
    className="text-[40px] font-bold tracking-wider text-white"
    style={{fontFamily: 'var(--font-heading)'}}
  >
    {brandName}
  </span>

  {/* シーズナルバッジ（右上） */}
  <span
    className="px-8 py-4 text-[26px] font-bold text-white tracking-widest uppercase"
    style={{background: 'var(--color-accent)', borderRadius: '9999px'}}
  >
    {badgeText}  {/* 例: "春限定" "新登場" */}
  </span>

</div>
```

## メインコンテンツカード（下部60%）

```jsx
{/* ContentCard — absolute bottom-0 で下部固定 */}
<div className="absolute bottom-0 left-0 right-0 z-10 flex flex-col justify-between px-16 pt-14 pb-16"
     style={{minHeight: '648px' /* 1080 × 60% */}}>

  {/* HeadlineBlock（左寄せ） */}
  <div className="flex flex-col gap-5 max-w-[800px]">

    {/* アイブロウ（eyebrow） */}
    <p
      className="text-[28px] font-semibold tracking-widest uppercase text-white/80"
    >
      {eyebrow}  {/* 例: "期間限定キャンペーン" */}
    </p>

    {/* メインヘッドライン */}
    <h1
      className="text-[88px] font-bold leading-tight text-white"
      style={{fontFamily: 'var(--font-heading)'}}
    >
      {headline}
    </h1>

    {/* サブコピー */}
    <p className="text-[36px] leading-relaxed text-white/85">
      {subCopy}
    </p>

  </div>

  {/* BottomRow — ベネフィット（左）+ CTA（右）のZ型配置 */}
  <div className="flex flex-row items-end justify-between mt-10 gap-8">

    {/* BenefitList（左下） */}
    <div className="flex flex-col gap-4">
      {benefits.map((benefit) => (
        <div key={benefit} className="flex flex-row items-center gap-4">
          <span className="shrink-0">
            <svg width="28" height="28" viewBox="0 0 24 24" fill="none"
                 stroke="var(--color-accent)" strokeWidth="2.5" strokeLinecap="round" strokeLinejoin="round">
              <polyline points="20 6 9 17 4 12"/>
            </svg>
          </span>
          <span className="text-[32px] font-medium text-white leading-snug">
            {benefit}
          </span>
        </div>
      ))}
    </div>

    {/* CTABlock（右下） */}
    <div className="flex flex-col items-end gap-5 shrink-0">

      {/* 希少性テキスト */}
      <p className="text-[26px] font-semibold text-white/90 text-right">
        {credibilityText}  {/* 例: "先着20名限定" */}
      </p>

      {/* CTAボタン */}
      <button
        className="flex flex-row items-center gap-4 px-12 py-7 text-[38px] font-bold text-white whitespace-nowrap"
        style={{background: 'var(--color-accent)', borderRadius: 'var(--radius-btn)'}}
      >
        {ctaText}
        <svg width="34" height="34" viewBox="0 0 24 24" fill="none"
             stroke="currentColor" strokeWidth="2.5" strokeLinecap="round" strokeLinejoin="round">
          <line x1="5" y1="12" x2="19" y2="12"/>
          <polyline points="12 5 19 12 12 19"/>
        </svg>
      </button>

      {/* 注記 */}
      <p className="text-[22px] text-white/65 text-right">
        {footnote}
      </p>

    </div>

  </div>

</div>
```

## 配置サマリー

| エリア | 配置 | 役割 | AIBAC |
|--------|------|------|-------|
| BackgroundImage | absolute inset-0 | 感情的インパクト | Attention |
| GradientOverlay | absolute inset-0 | Z型可読性確保 | — |
| HeaderBar | absolute top-0 | ブランド認知 + バッジ（Z型左上→右上） | Credibility / Attention |
| HeadlineBlock | absolute bottom（上部） | 課題共感 + 訴求（Z型左下） | Interest |
| BenefitList | absolute bottom（左下） | 具体的メリット | Benefit |
| CTABlock | absolute bottom（右下） | 希少性 + 行動喚起（Z型右下） | Credibility / Action |

---

## `absolute` 使用の制限（このサイズ限定の例外）

```
許可: BackgroundImage の absolute inset-0
許可: GradientOverlay の absolute inset-0
許可: HeaderBar の absolute top-0
許可: ContentCard の absolute bottom-0
禁止: それ以外の要素への absolute の使用
```

---

## コンテンツ文字数制限

| 要素 | 上限 | 理由 |
|------|------|------|
| headline | 14文字/行（2行まで） | 88px × 幅800pxの限界 |
| subCopy | 28文字 | 2行に収まる限界 |
| benefit各項目 | 18文字 | 1行に収まる限界 |
| badgeText | 6文字 | バッジ幅に収まる限界 |
| ctaText | 10文字 | ボタン幅に収まる限界 |

---

## nanobanana アスペクト比

このサイズで `gemini_generate_image` を呼ぶ前に必ず以下を実行:
```
set_aspect_ratio: "1:1"
```

---

## 禁止事項

- 外部画像URL の使用禁止（Base64のみ）
- 絵文字の使用禁止（SVGアイコンで代替）
- ContentCard 内での `absolute` の使用禁止
- BenefitList を4項目以上にすることを禁止
