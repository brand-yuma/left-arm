# フレグランスブランド（2024〜2026）

**月商 4,000円 → 90万円**

## 入口

線香ブランドを2人で運営していたクライアントにジョインする形で参画。

## 最初の意思決定：線香→香水へ即転換

- 線香はインテリア系インフルエンサー等により印象回復傾向だったが、一般的には仏事のネガティブイメージが根強い
- 単価が低く、予算のないブランドがその市場で戦うのは困難
- 香水は容量・濃度で単価の幅を作れる → 価格設計の自由度がある

## 製品からサービスへの転換

**きっかけのエピソード**：
ブランドオーナーの友人から「彼女が耳をすませばのヒロインに似ているのでそのイメージの香りを作ってほしい」という依頼。オーナーがジブリ好きで試したところどんぴしゃ。紅の豚バージョンも制作。
→ **「抽象的な香りを再現するのがうまい」という強みを発見**。

## サービスコンセプトの設計

抽象的な香りの再現が最大化する対象として「人生」を着想。

**市場背景**：コロナ禍・終身雇用崩壊・老後2000万問題により「自分の人生は自分で責任を取る時代」へ。フリーランス急増と「自分って何者？」という自分迷子が増え、コーチング市場・スピリチュアル市場が急伸。

→ **ヒアリングベースのオリジナル香水サービス**として設計：
- 香水のトップ・ミドル・ベースノート（香りの変化）＝過去・現在・未来を表現
- その人だけの人生を表した唯一無二の香水＝アイデンティティや信念を香りで感じるお守り

## 検証

60人モニターを実施。価値軸は「ストーリー性」「自分を語れる香水」と確認。営業マン層にも刺さった。

## 成果

- スタート価格：約1万円（本人は「安すぎるミス」と自覚）→ 月30人・30万円
- 約5ヶ月後：ボトル刷新等の設備投資を経て単価を4万円台へ
- 月15人×4万円台 = 月60万円以上
- toBの展開もあり

## toB：企画提案型OEM

通常OEMを受けていた時期は利益率16%（100本受注しても粗利20万以下）。単発で終わりがちで、クライアント側も「思ったより儲からない・売れない」となって継続しにくかった。

→ **企画提案型OEMに転換**：原価を引いた粗利を折半するモデルへ変更 → 利益率34%まで改善。

強みはCDスキルを活かした「企画提案ができるOEM制作」。単なる製造ではなく、何をどう売るかも含めて提案できる。

**具体例**：ギフト需要に応えるバラ屋さんとの共同OEM（販売開始待ち）。

## この支援から読み取れる手法

- ジョイン即座に事業モデルごと転換を提案できる判断速度
- 偶発的エピソードから「コアの強み」を見抜く観察力
- プロダクトの構造（トップ/ミドル/ベース）を概念設計（過去/現在/未来）に転用する発想
- マクロ社会トレンドとミクロの強みを接続するポジショニング

**モデルごと変える判断について**：「課題とその解決にクライアントのアセットをフル活用する前提で考えた結果、モデルごと変わった」という感覚。意図的に「モデルを変える」のではなく、制約と資産の中で本質的に解こうとすると自然とそうなる。
